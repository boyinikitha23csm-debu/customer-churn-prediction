# Customer Churn Prediction

## Project Description
A machine learning application that predicts whether a customer is likely to churn.

## Machine Learning Model
Random Forest Classifier

## Platform
Snowflake

## Features
- Age
- Income
- Tenure
- Monthly Charges

## Target
CHURN

0 = Customer may stay  
1 = Customer may churn

## Technology
- Python
- Snowflake
- Snowflake ML Model Registry
- Streamlit
- Random Forest
